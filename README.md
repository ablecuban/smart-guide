# 🔐 SmartGuard – Arduino-Based Security System

SmartGuard is an embedded security project built using Arduino and electronic sensors to detect unauthorized movement and provide real-time alerts.

The system uses a Passive Infrared (PIR) motion sensor to identify movement within a monitored area. When motion is detected, the system activates an alarm and displays the current security status.

## 🚀 Features

- Motion detection using PIR sensors.
- Automatic buzzer alarm activation.
- LED security status indicators.
- LCD display for real-time monitoring.
- Adjustable detection sensitivity.
- Low-cost and easy-to-build hardware design.

## 🔧 Hardware Requirements

- Arduino Uno
- PIR Motion Sensor (HC-SR501)
- Buzzer
- LEDs
- 16x2 LCD Display
- 220Ω Resistors
- Breadboard
- Jumper Wires

## ⚙️ How It Works

1. The PIR sensor continuously monitors the surrounding environment.
2. When movement is detected, the Arduino receives a signal.
3. The buzzer activates to indicate possible intrusion.
4. An LED indicator changes to show the security status.
5. The LCD displays the detection message.
